    Azure Blueprint

    Challenge
    Azure resource diagrams, Bicep dependencies and CI/CD job graphs are often taught separately, making the path from architecture to deployment hard to follow.
    Solution
    An interactive course with animated SVG lessons, a browser-based YAML graph debugger and guided pipeline exercises.
    Result
    26 lessons across 7 modules, 10 practice exercises and 8 cheatsheets. Supports GitHub Actions, Azure DevOps and GitLab CI without a backend.

    Tech stack:

    • JavaScript
    • SVG
    • HTML / CSS
    • Bicep
    • Azure CLI
    • GitHub Actions
    • Azure DevOps
    • GitLab CI
    Read the engineering case study — Azure Blueprint

    My role

    Creator and maintainer. Designed interactive architecture lessons and pipeline debugging tools.

    Architecture

    A static JavaScript application connects a lesson engine, SVG diagrams and a YAML dependency graph. Pipeline validation and simulation run in the browser without a backend.

    Azure and infrastructure

    Bicep examples define App Service, Storage, managed identity, Application Insights and Log Analytics. They demonstrate resource dependencies, HTTPS and telemetry; application code and storage role assignments are outside the sample.

    CI/CD

    GitHub Actions, Azure DevOps and GitLab CI examples share a lint → what-if → approval → deploy → smoke-test flow with federated identity. The course itself uses a separate validation and GitHub Pages publishing workflow.

    Decisions and results

    The graph debugger detects cycles and missing dependencies, then simulates parallel jobs, approval gates and failure propagation. Browser execution keeps pipeline text off a server. The simulator simplifies provider behavior and treats conditions as true; it does not run deployments.

    Vectaris

    Challenge
    Teams running LLMs and agents in production lack a single view of usage, latency, cost and agent health.
    Solution
    A unified observability layer that aggregates telemetry from LLM endpoints, agent runtimes and cloud cost APIs, with an LLM proxy that captures tokens and latency.

    • Kubernetes

  • Open-source build Security

    PQE — Post-Quantum Encryption

    Challenge
    Quantum computers will break RSA and elliptic-curve cryptography. Organizations need a concrete, testable path to NIST's post-quantum standards.
    Solution
    A .NET 10 reference solution implementing ML-KEM (FIPS 203), ML-DSA (FIPS 204) and SLH-DSA (FIPS 205), plus hybrid classical + PQC migration patterns.
    Result
    Clean-architecture solution with an ASP.NET Core API, OpenTelemetry instrumentation, unit, integration and security test suites, and BenchmarkDotNet benchmarks.

    Tech stack:

    • C#
    • .NET 10
    • ASP.NET Core
    • OpenTelemetry
    • BenchmarkDotNet
    GitHub — PQE — Post-Quantum Encryption (opens in a new tab)

    Hyperscale Observability Platform

    Challenge
    Diagnosing packet loss across a global software-defined network means correlating enormous telemetry volumes in near real time.
    Solution
    An OpenTelemetry pipeline on Azure — Event Hubs, AKS with KEDA and Azure Data Explorer — with loss attribution, causal-graph analysis and a diagnostics API.
    Result
